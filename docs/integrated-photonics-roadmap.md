# Integrated photonics ROM roadmap

The first consumer is a differentiable multimode slab propagator. A directional-coupler model follows, then an MMI model. Device layout, port definitions, effective-index reduction, optimization policies and compact models belong downstream. A taper will consume a sequence of local bases and their couplings.

## Implementation order and acceptance

1. **Stabilize the physical result contract.** The first increment adds an owned sampled profile for arbitrary and pole-normalized fields. Preserve the existing point API. Record the phasor convention, propagation and transverse axes, impedance scaling, origin, interface sides, exterior branches and normalization. Signed longitudinal power per unit invariant width now includes analytic exterior tails for lossless dielectric guided modes. The left-interface primary field fixes the phase, with an explicit conditioning check. Validate TE and TM against symmetric and asymmetric slabs and under arbitrary seed rescaling.
2. **Enumerate the guided basis at a real wavelength.** Start with positive-index isotropic lossless dielectric stacks. State the real β interval, direction, polarization and cutoff margins. Reconcile an independent guided-mode count with accepted distinct roots, including higher orders. Return expected/found counts, unresolved regions and a conditional completeness status. Validate against analytic slab ladders and one-sided cutoff sweeps. This supplies the modal set for slab propagation.
3. **Differentiate eigenvalues and fields on that basis.** Define parameter directions using the existing core stack. Distinguish thickness changes, displacement of one interface with its neighbours fixed, a rigid translation, and material-index/model parameters at fixed vacuum wavelength. For a regular root use β′ = −Fₚ/Fᵦ and dk₀/dλ = −2π/λ² in consistent units. Differentiate the field reconstruction along that root, including coordinate motion, unit-power scale and phase choice. State whether an observation is fixed in the lab, at a layer fraction or attached to an interface side. Validate directional derivatives with converging perturbations, including rigid translations, discontinuous normal components and dispersive material models.
4. **Validate the first downstream slab propagator.** Given βₘ, normalized fields and their derivatives, propagate supplied modal amplitudes by exp(iβₘL). Check multimode beating, phase sensitivity and reconstructed fields against analytic slabs. This exercises a consumer without root-search or scattering-matrix access. Excitation from a physical port field follows with overlaps.
5. **Implement guided cross-section overlaps and geometry sweeps.** Require a common frequency, coordinate registration and explicit electromagnetic convention. Give scalar overlaps their own API. Start with the conjugated guided-power product and distinguish it from an unconjugated reciprocity pairing. Integrate over the union of both structures' interfaces and their exterior tails. Differentiate integrands and moving limits using one-sided values; specify one-sided derivatives when interfaces coincide and perturbation order matters. Check self-power, orthogonality, symmetry under exchange where applicable, and total derivatives. Use predicted β and normalized field overlap to match modes across stack perturbations. Return ambiguous clusters/subspaces and refresh enumeration when counts change. Validate on the two-core supermodes.
6. **Expose projection data and feature sensitivities.** Supply ordered modes, their conventions and a conditioned Gram matrix so downstream consumers can form excitation coefficients and interface projections. Validate a directional-coupler ROM against supermode beating, then an MMI ROM against a higher-order basis with convergence in retained modes. Unit-power guided overlaps are the first scope; open-system biorthogonal overlaps need a separate convention. Retain the Page stopped-light case for subsequent stationary-point refinement, sensitivity to layer motion and optimization in lamina-design. Mode volumes and other QNM observables remain a separate milestone.

The API decisions with the highest cost to change are field phase and normalization, transverse frame and sided coordinates, the perturbation and observation held fixed, and the distinction between an individual mode and a nearly degenerate subspace. Resolve these before promising persistent mode identifiers or exposing device-facing expansion coefficients.

## Layer-resolved quantities for optimization

- **With guided-power differentiation (step 3).** Retain the signed longitudinal power and its directional derivative in each finite layer and each exterior. Use the same integration grid, moving layer measures, analytic tails and normalization as the eigenfields. Check that the regional contributions sum to signed unit power and that the derivatives sum to zero. Keep the sided interface fields available for boundary objectives.
- **With overlaps (step 5).** Build reusable scalar and electromagnetic regional integrals on the same sided-coordinate contract. Use explicit weighting and units for material overlap and confinement. Validate derivative contributions from moving limits and discontinuous integrands.
- **With projection and feature sensitivities (step 6).** Add dispersion-weighted energy or absorption observables when their physical conventions and validation cases are established. Connect open-system integrals and mode volumes to the separate QNM milestone. Keep device objectives in downstream code, using owned results from lamina-mode and shared reconstruction and integration primitives from lamina-core.

## Tracked bases and projection

`track_guided_basis` takes a counted source basis and one registered geometry or material step at fixed wavelength, polarization and propagation direction. It predicts roots from the supplied perturbation. Local corrections must occupy distinct counted root brackets and account for the destination mode count. A failed coverage check triggers independent enumeration. The result reports matched indices, unresolved assignment clusters, and unmatched modes. The coupled-slab benchmark checks local recovery against independent enumeration, and the slab cutoff benchmark checks the lost-mode path.

`project_guided_field` takes an ordered complete basis and a supplied field in the same physical convention. The caller declares its finite support and any internal interfaces, including one-sided limits. The projection uses the Hermitian power Gram matrix, returns singular values and numerical rank, and provides coefficients and a residual for a full-rank basis. Choose support that captures the supplied field to the required accuracy. The solver reconstructs the test modes' evanescent tails from their exterior boundary fields and accepted decay constants. Two complex coefficients are recovered within 1e−7 in the slab regression, which also exercises rank deficiency.

These results implement the tracked-basis and conditioned-projection parts of the [target development guide](target-development-guide.md). Unconjugated reciprocity, local coupling coefficients, and the approximate 2D and propagation crates remain later milestones.
